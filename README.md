# Un site en français sur le réchauffement climatique

Ce dépôt contient les sources Jekyll d'un site de Hugo Herbelin sur le
réchauffement climatique.

## Poster un commentaire

L'ajout de commentaire se fait depuis le site avec giscus, qui produit
une pull request.

## Poster un message

Le blog est ouvert à des billets extérieurs soumis par pull requests.

## Pour tester la construction du site

1. Prérequis :

    * [Ruby](https://www.ruby-lang.org/en/) and [Bundler](https://bundler.io)
    * [Jekyll](https://jekyllrb.com)

2. Pour préparer le site, exécuter `bundle install` dans le dépôt
3. Pour créer le site localement sur http://localhost:4000/, exécuter
   `bundle exec jekyll serve`.

Note : Merci au site [Mathematics and Computation](math.andrej.com)
qui a servi d'inspiration pour l'infrastructure technique.
